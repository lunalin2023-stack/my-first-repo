# Tactical Command Edition

## 1. Game Description

Tactical Command Edition is a single-player,
turn-based naval strategy and logic puzzle game
inspired by Battleship.

Players must locate and destroy the enemy fleet
using attacks, numerical clues and tactical
power-ups.

## 2. Game Features

- 10 x 10 coordinate grid
- Hidden ship placement
- Hit and miss detection
- Numerical clues based on neighbouring ship segments
- Cash and tactical shop system
- Radar and other power-ups
- Computer-controlled opponent

## 3. How to Run

Run the following command:

python main.py

## 4. Project Structure

- main.py: Main game controller
- board.py: Board management
- ship.py: Ship management
- combat.py: Combat system
- logic.py: Logic puzzle system
- computer.py: Computer AI
- shop.py: Economy and shop system
- display.py: User interface

## 5. Development Environment

- Python 3.13
